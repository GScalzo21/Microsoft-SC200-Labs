# 🛡️ Microsoft SC-200 Practice Labs: Defender XDR, Sentinel & Azure Security

This repository contains a growing collection of **hands-on labs** designed to help prepare for the **Microsoft SC-200: Microsoft Security Operations Analyst** certification exam.

Each lab simulates real-world attacker behavior and includes detection, investigation, and response practices using **Microsoft Defender XDR**, **Microsoft Sentinel**, and other tools within the Microsoft Security stack.

---

## 🎯 Goals

- Strengthen my threat hunting and SOC analyst skills
- Practice real-world incident response workflows
- Build a portfolio of Microsoft security investigations
- Prepare for the SC-200 exam through hands-on experience

---

## 🧰 Tools Used

- Microsoft Defender XDR (`https://security.microsoft.com`)
- Microsoft Sentinel
- Azure Portal & Azure Security Center
- Kusto Query Language (KQL)
- Log Analytics

---

## 📁 Lab Structure

Each lab is located in its own folder and includes:

- A `README.md` with the lab scenario, summary, tools used, and key takeaways
- Screenshots of critical investigation steps
- KQL queries used for detection or hunting
- A documented attacker technique (mapped to MITRE ATT&CK where possible)

## 📌 Topics Covered

This lab series covers major objectives in the SC-200 exam, including:

- Threat detection and response in Microsoft Defender for Endpoint
- Investigating identity-based threats
- Creating and tuning KQL queries in Microsoft Sentinel
- Simulating attack scenarios like malware execution, lateral movement, data exfiltration
- Leveraging telemetry across Defender and Azure environments
